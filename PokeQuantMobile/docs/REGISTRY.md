# File & Worker Registry

Per-file orientation notes. The codebase is structured as: screens are
composition shells, `src/hooks/` (or `src/scanner/hooks/`) own store/async
wiring, leaf components are `memo()`'d, shared styles live in a sibling
`*Styles.ts` module.

- `src/api/supabaseClient.ts` — Supabase client.
- `src/api/sessionStorage.ts` — `expo-secure-store` session cache.
- `src/api/cloudSync.ts` — Turso edge sync engine; `getAuthToken()` falls back to stored session.
- `src/db/database.ts` — tenant SQLite init and Drizzle.
- `src/db/inventoryDb.ts` — headless CRUD for `inventory`, image URL sanitization, remote-row coercion.
- `src/db/catalogDb.ts` — catalog DB facade re-exporting catalogSession/catalogPrices/catalogSignals/catalogSearch (see AGENTS.md "Core Database"); `setCatalogDatabase` lives here, card-search builders in `src/db/catalogSearch.ts`.
- `src/scanner/services/deal/*` — deal engine: classifier, series features, stock health, buy scout, shift tracker, glosses. See `docs/DEAL_ENGINE.md`.
- `src/db/eventCatalogDb.ts` — raw SQLite for per-show event inventory, fuzzy image matching.
- `src/db/schema.ts` — Drizzle schema for `pokequant.db`.
- `src/store/*` — Zustand stores.
- `src/services/CatalogDownloadService.ts` — catalog DB download and price refresh.
- `src/services/CatalogImageService.ts` — EN + JP image ZIP download and native extraction (union index).
- `src/services/ExportService.ts` — RFC 4180 CSV export (inventory + completed sales) via `expo-file-system/next` + `expo-sharing` (RN `Share.share` fallback).
- `src/services/EventCatalogDownloadService.ts` — per-show event catalog download and extraction.
- `src/services/errorReporting.ts` — crash/error reporting sink gate (`@sentry/react-native`, lazy `require`; DSN + `!__DEV__` gated init, `logError`→sink bridge via `utils/log.setErrorSink`; fatal-JS capture owned by Sentry's default `ReactNativeErrorHandlers` integration — do not double-wrap `ErrorUtils`).
- `src/services/ShowListService.ts` — active show list with cache/fallback.
- `src/services/showVendorService.ts` — vendor inventory and team CRUD worker client.
- `src/services/revenueCat.ts` — RevenueCat wrapper and helpers.
- `src/screens/ShowVendorScreen.tsx` — vendor upload/publish UI; brain in `hooks/useShowVendor.ts`, tab panels in `components/shows/` (`VendorSetupCard`, `PickCardsPanel`, `ListingsPanel`, shared `showVendorPanelStyles`).
- `src/screens/OrganizerScreen.tsx` — show-organizer management (create/edit shows, approve requests, payment ledger, SMS reminders). Composition shell: `hooks/useOrganizerShows` (shows + roster loads), `useShowForm` (create/edit fields + save), `useVendorAdd` (app-vendor pick vs manual attach), `useRegActions` (approve/reject/pay/assign/remind commits + modal targets). Rendering in `components/organizer/` — `ShowListMode`, `ShowDetailMode`, `ShowFormModal` (unified new/edit), `AddVendorModal`, `RegActionModals` (approve/pay/assign/remind), `RegistrationRow`, `OrganizerField`, `OrganizerModalSheet`, `organizerStyles`. SMS/name helpers in `services/organizerText`.
- `src/screens/ShowsScreen.tsx`, `src/screens/EventListScreen.tsx`, `src/screens/EventSearchScreen.tsx` — attendee show browsing. `EventListScreen` brain is `hooks/useEventList.ts` (3-stage cached→vendor→fresh load); `components/shows/ShowCard.tsx` + `EventListNotices.tsx` are its leaves. `EventSearchScreen` brain is `hooks/useEventSearch.ts`; `components/events/` holds `EventSearchPage`/`EventFilterBar`.
- `src/screens/InventoryScreen.tsx` — three-segment working surface (Cards / Radar / Analytics): grid + velocity breakdown, Resticker Radar repricing, LiveSessionAnalytics + PerformanceAnalytics. The old Home tab was dissolved into this screen; `SyncBadge`/`CatalogTimestamp` live in the status row. Shell over `hooks/useInventoryScreen.ts` (edit/analysis sheets, search, metrics, hero art, stock health, viewport) which composes `hooks/useInventorySignals` (catalog pipeline: 500ms-debounced velocity windows + CardSignal map + held/watched deal-class shift diffs via `dealShiftTracker`; keyed dedup so inventory edits that don't change product coverage don't reload), `hooks/useDeepFeatures` (background `price_series` hydration → `buildSeriesFeatures` for stock-health refinement; scalar reads stand on failure), `hooks/useBulkSelection` (long-press/toolbar select, two-tap 3.5s delete confirm). Leaf components own their styles: `components/SearchBar`, `PortfolioHero`, `InventoryCell` (exports `GRID_GAP`), `VelocityBreakdown`, `StockHealthPanel`, `RotationSheet`, `ShiftBanner`, `BulkActionBar`; screen styles in `screens/inventoryStyles.ts`. Pure helpers: `services/inventorySearch.ts` (search index — shared with ShowVendorScreen), `services/inventoryReads.ts` (`signalForCard`/`featuresForCard` finish fallback), `services/portfolioVelocity.ts` (velocity window aggregation + `ProductVelocity`). `BUCKET_COLOR` lives in `deal/stockHealth.ts` next to `BUCKET_LABEL`/`BUCKET_DESC` — one owner for bucket vocabulary.
- `src/screens/ScannerScreen.tsx` — card scanner phase gate (assets check → download gate → camera/queue views + background warm-up). The live pipeline is `scanner/organisms/ScannerCameraView.tsx` (capture → processPhoto → review, verbatim shutter path); meter plumbing in `hooks/useScanMeter.ts`, trade state in `hooks/useTradeScan.ts`; chrome in `scanner/molecules/` — `ScannerTopBar`, `ScannerBottomBar`, `LastAddedPill`, `CameraFallbacks`, `ScannerOverlays` (warming + processing), `scannerScreenStyles`. The review queue is `scanner/organisms/ScanQueueView.tsx` (shell) over `scanner/hooks/useScanQueue.ts` + `ScanQueueRow`/`VariantSwitchSheet`/`AmountSheet` molecules.
- `src/scanner/*` — scanner module (atoms/molecules/organisms UI, `hooks/` — including `useAnalysisSheet`, the shared name-tap→deal-analysis plumbing — services, `store/scanQueueStore.ts`, types, utils).
- `src/screens/SearchBuyScreen.tsx` — catalog search, filters, buy scout; composes `useCatalogDb` + `useCatalogSearch` + `useBuyScout`; styles in `screens/searchBuyStyles.ts`.
- `src/screens/SettingsScreen.tsx` — composition shell (~90 lines: expanded-map + scrollRef + section JSX) over `components/settings/`: `BuyTiersSection` (tier inputs + `skipSyncRef` sync guard + `scrollRef` prop for add-tier autoscroll), `StickerRulesSection`, `ImportExportSection` (owns `BulkImportWizard`), `OfflineDataSection` (price refresh + EN/JP image packs; JP also warms the scanner embedding sidecar), `SubscriptionSection` (founder/pro status + owns the paywall Modal), `TeamSection` (owner roster/invite lifecycle, member view, redeem field), `AccountSection` (sign out + delete). Shared stylesheet `components/settings/settingsStyles.ts`; numeric-input parse/validate helpers in `utils/numberInput.ts`; the mount refresh (RevenueCat → worker sync → profile+team) is `hooks/useSettingsBootstrap.ts`. Sections own their store subscriptions — the screen's only store contact is the bootstrap hook's action refs.
- `src/components/SetupGate.tsx`, `src/components/SubscriptionGate.tsx`, `src/components/PricingPreview.tsx` (split into `components/pricing/`: `planData`, `PackageCard`, `TeamInviteSection`, `PricingFooter`), `src/components/PerformanceAnalytics.tsx`, `src/components/CartDrawer.tsx`, `src/components/BulkImportWizard.tsx` (brain `hooks/useBulkImport.ts`, helpers `components/import/importRows.ts`, row `ImportRowCard`).
- `src/components/PerformanceAnalytics.tsx` — ~100-line composition shell: horizon state + memos + JSX. Math in `services/salesAnalytics.ts` (bucketing, horizons, metrics/tiers — pure over `CompletedSale`), DB reads in `hooks/useAnalyticsLookups.ts` (trade tags + class track record), leaf views in `components/analytics/` (TimeHorizonFilter, HeroKPIs, VelocityChart, MarginWaterfallChart, TierBreakdownChart, ChartCarousel — exports `carouselStyles` the sales stream borrows for dots, CompletedSalesStream, ReadTrackRecord), semantic palette in `components/analytics/palette.ts`.
- `src/components/ShowVendorInventoryRow.tsx`, `src/components/ShowVendorListingRow.tsx`, `src/components/EventSearchCard.tsx`.
- `src/components/JpBadge.tsx` + `src/utils/jp.ts` — `JP · ` set-prefix detection and badge.
- `worker.js` and `wrangler.jsonc` — production sync proxy (`pokequant.totees-mart.workers.dev`): the only tenant egress to Turso for `inventory`/`vendor_settings`/`sync_metadata` — POST-only `/v2/pipeline` forwarder with ES256 JWT auth, SQL allowlist, `user_id` force-binding. PWA-era surface retained; characterization pins in `__tests__/workerSync.test.ts`.
- `worker_show_vendor.js` (entry stub) + `worker_show_vendor/` (dispatch → handlers → domain modules) and `wrangler.show_vendor.jsonc` — vendor CRUD worker.
- `worker_pre_show.js` and `wrangler.pre_show.jsonc` — pre-show snapshot worker.
